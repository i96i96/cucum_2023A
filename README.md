## 主要创新点

1. **层次化邻域遮挡检测**：空间网格粗筛(L1) → 方向性投影包围盒阈值截断(L2，阈值随距离自适应) → 射线-矩形精确求交(L3)，将阴影遮挡检测的 `O(N²)` 降为 `O(N·k)`（实测 k≈13.2，加速约 132 倍）。
2. **截断效率解析—数值混合**：远场镜面用椭圆高斯卷积解析积分，近场镜面用 Buie 太阳形状重要性采样追迹，由无量纲光斑尺寸阈值切换。
